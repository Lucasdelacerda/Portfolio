# ☕ Portfólio — Lucas de Lacerda

Portfólio pessoal para apresentar meu trabalho como desenvolvedor Back-End Java, compartilhar projetos e facilitar o contato sobre novas oportunidades.

## ✨ O que você encontra

- **Apresentação:** introdução e disponibilidade para novos projetos.
- **Trabalhos:** espaço para apresentar projetos, suas descrições e tecnologias.
- **Sobre mim:** resumo da minha atuação e das ferramentas que uso.
- **Contato:** links para falar comigo por e-mail, WhatsApp ou LinkedIn.
- **Layout responsivo:** navegação adaptada para diferentes tamanhos de tela.

> 🚧 Os cards de projetos estão preparados para receber conteúdo real. Atualize os exemplos antes de publicar o portfólio.

## 🧰 Tecnologias

- **React 18** — construção da interface.
- **JavaScript** — lógica da aplicação.
- **Vite 6** — servidor de desenvolvimento e build.
- **CSS** — estilos e layout responsivo.
- **Tecnologias apresentadas no portfólio:** Java, Spring Boot, Docker, JUnit, React, JavaScript e Tailwind CSS.

## 🚀 Começar

### Pré-requisitos

- [Node.js](https://nodejs.org/) (inclui o npm)
- Git

### Instalação e desenvolvimento

```bash
git clone https://github.com/Lucasdelacerda/Portfolio.git
cd Portfolio
npm install
npm run dev
```

O Vite exibirá no terminal o endereço local para abrir no navegador.

## 📦 Build de produção

```bash
npm run build
```

Os arquivos prontos para publicação serão gerados na pasta `dist/`. Para conferir localmente a versão de produção:

```bash
npm run preview
```

## 🛠️ Personalização

1. Edite os textos e os dados dos projetos em [`src/App.jsx`](./src/App.jsx).
2. Ajuste cores, tipografia e layout em [`src/App.css`](./src/App.css).
3. Troque ou adicione ícones em `public/icons/` e atualize os caminhos em `src/App.jsx`.
4. Revise os links de contato e redes sociais antes de publicar.
