# Portfólio pessoal

Portfólio de Lucas de Lacerda, desenvolvido com React e Vite.

## Requisitos

- Node.js
- npm

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

## Estrutura

- `src/`: interface React e estilos.
- `public/icons/`: ícones usados na seção de tecnologias.
- `index.html`: documento HTML de entrada.
